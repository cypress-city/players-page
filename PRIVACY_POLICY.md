# Privacy Policy
This document describes in full detail what data the Players' Page Discord integration distributed by the author (hereafter referred to as "the Application") collects and stores long-term, as well as how to delete said data.

This document may be changed as the needs and functionalities of the Application change. This file represents the most recent version of this document.

## What the Application Doesn't Store
The Application does not store any email addresses, usernames, server names, names for server attributes such as channels or emotes, or message content under any circumstances.

## What the Application Stores
The Application stores two kinds of potentially sensitive data: snowflakes and update tokens.

A "snowflake" is a unique integer ID generated by Discord for each user.
Snowflakes are public and may be seen by any other Discord user at any time.
Like most Discord services, the Application identifies users by their snowflakes.

An "update token" is a unique UUID generated by the [Mario Kart World Players' Page](https://www.mariokart64.com/mkworld/) for each site member, functioning as a passkey.
**When a Discord user uses the `/register` command and provides their update token, the Application saves it in a local database alongside the user's snowflake.**
The Discord user (hereafter referred to as "the User") provides this information voluntarily to the Application.

The Application is operated by Players' Page staff, and is fully authorized to collect and store this information on behalf of the Mario Kart World Players' Page.
Only the official Discord integration (Discord ID `Players' Page#4618`) has this authorization.
Do not share your update token with any other Discord applications.

The author of this software may view and edit the database at any time, and is acting on behalf of the Mario Kart World Players' Page.
No other users can see your update token.
This data is not shared with third parties except as required by law or by Discord's terms of service.

This data allows the Application to submit the User's Time Trial records to the Mario Kart World Players' Page via Discord commands.

No other data of any kind is stored by the Application.

## How to Remove Your Data
All user data can be managed via the Application itself.
* `/token view` displays the User's currently stored update token, if any.
* `/token delete` immediately and permanently removes the User's snowflake and update token from the Application's database.
